# AutomationExercise — QA Automation

This project aims to automate the main features of the Automation Exercise website and validate whether the application behaves as expected.

The tests will cover important user journeys such as:

* User registration and login
* Product search and navigation
* Adding and removing products from the cart
* Checkout process
* Form validation
* Invalid and unexpected scenarios
* API functionality

The main goal is to identify possible problems, validate the application's behavior and ensure that the most important features continue working correctly.
